# Sample data

Generated by `python3 tools/make_seed.py Book2.xlsx` from the 22 lodge records listed in the project brief.

* `members.json` – members in the internal data model. **Phone numbers and e-mail addresses are intentionally left empty** so a public repository does not expose personal contact data.
* `ledger.json` – empty (no payments are bundled).
* `seed.json` – members + ledger + default settings (the first-run data set; also embedded in `js/seed-data.js`).
* `treasury-summary.json` – revenue per contribution year of the sample ledger.

Import samples in the exact `Book2.xlsx` column layout live in `assets/samples/` (XLSX, CSV, JSON).
